# iOS：用快捷指令实现 Send to KOReader

iOS 上不需要装 App：一个快捷指令就能出现在分享菜单里，把电子书直接 PUT 到 WebDAV 文件夹。KOReader 端配置和安卓相同（见 [README](../README.md#koreader-端)）。

动作名称同时给出中文和英文（括号内），iOS 版本不同措辞可能略有差别，在动作搜索框里搜关键词即可。

## 准备

- WebDAV **文件夹**地址，结尾不要带 `/`，例如 `https://example.com/dav/books`
- 用户名、密码
- 地址里有中文时，先换成百分号编码形式，例如 `书库` → `%E4%B9%A6%E5%BA%93`（可在电脑浏览器地址栏粘贴后复制得到，或用任意在线 URL 编码工具）

## 搭建

打开「快捷指令」App → 右上角 **+** 新建，命名为 **发送到 KOReader**。

### 1. 设为分享菜单入口

点顶部名称旁的下拉箭头 → **详细信息（Details）** → 打开 **在共享表单中显示（Show in Share Sheet）** → 完成。

编辑器顶部会出现「从 *共享表单* 接收 *任何* 输入」：

- 点 **任何**，只勾选 **文件（Files）**
- 点 **如果没有输入（If there's no input）** → 选 **停止并回应（Stop and Respond）**

### 2. 账号信息

依次添加：

1. **文本（Text）**：内容填文件夹地址，例如 `https://example.com/dav/books`。长按这个动作 → **重新命名（Rename）** 为 `文件夹`（不能重命名的旧版本，就记住它是第一个「文本」）。
2. **文本（Text）**：内容填 `用户名:密码`（中间是英文冒号）。
3. **Base64 编码（Base64 Encode）**：输入选上一步的文本；点 **显示更多** → **换行（Line Breaks）** 选 **无（None）**。不选「无」的话长密码会被折行，导致认证失败。

### 3. 逐个上传

4. **对每个项目重复（Repeat with Each）**：输入选 **快捷指令输入（Shortcut Input）**。以下动作都放在「重复」块里面。
5. **文本（Text）**：插入变量 **重复项目（Repeat Item）** → 点它 → 选 **名称（Name）**；接着输入一个英文句点 `.`；再插入一次 **重复项目** → 点它 → 选 **文件扩展名（File Extension）**。结果形如 `重复项目名称.重复项目文件扩展名`。
6. **URL 编码（URL Encode）**：编码上一步的文本（文件名里的空格、中文、`#` 等会被转义）。
7. **文本（Text）**：插入变量 `文件夹`（第 1 步） → 输入 `/` → 插入 **URL 编码后的文本（URL Encoded Text）**。
8. **获取 URL 内容（Get Contents of URL）**：URL 选上一步的文本，点 **显示更多**：
   - **方法（Method）**：`PUT`
   - **头部（Headers）** → 添加新头部：键 `Authorization`，值输入 `Basic `（Basic 后有一个空格）再插入第 3 步的 **Base64 编码结果（Base64 Encoded）**
   - **请求体（Request Body）**：选 **文件（File）**，文件选 **重复项目（Repeat Item）**

「重复」块结束后：

9. **显示通知（Show Notification）**：`已发送到 KOReader`。

整体结构：

```
从 共享表单 接收 文件
文本 [文件夹地址]
文本 [用户名:密码]
Base64 编码 [文本]（换行：无）
对 [快捷指令输入] 中的每个项目重复
    文本 [重复项目.名称].[重复项目.文件扩展名]
    URL 编码 [文本]
    文本 [文件夹]/[URL 编码后的文本]
    获取 URL 内容  PUT  Authorization: Basic [Base64 编码结果]  请求体: 重复项目
结束重复
显示通知 "已发送到 KOReader"
```

## 使用

在「文件」、Safari、微信（右上角 ··· → 用其他应用打开）等任意地方分享电子书，在分享菜单里选 **发送到 KOReader**。第一次运行时 iOS 会询问是否允许连接你的服务器，选 **始终允许**。

**第一次请到云盘里确认文件确实上传了。** 「获取 URL 内容」遇到 401（密码错）、404/409（文件夹不存在）不一定会报错，通知只表示请求已发出。

## 和安卓版的区别

- 文件夹不存在时不会自动创建，需先在云盘里建好
- 没有上传进度条，大文件需要等一会儿通知才出现
- 无法可靠地判断上传失败（见上）

## 分享给别人

快捷指令里明文存着你的地址和密码。通过 iCloud 链接分享前，在 **详细信息** 里设置 **导入问题（Import Questions）**，把第 1、2 步的两个文本设为导入时由对方填写，再把内容改成占位文字；或者干脆分享一份清空了账号的副本。
